# Olympic Medal Prediction using Machine Learning

This project is a beginner-level machine learning project that uses Olympic team data to predict the number of medals a team may win.

The project explores the relationship between factors such as the number of athletes and medals won in previous Olympic Games, and uses Linear Regression to predict the number of medals.

## Project Overview

The goal of this project is to build a simple machine learning regression model that predicts Olympic medal counts based on historical data.

The project follows a basic machine learning workflow:

1. Load the dataset
2. Select relevant features
3. Explore correlations between variables
4. Handle missing values
5. Split the data into training and testing sets
6. Train a Linear Regression model
7. Generate predictions
8. Evaluate model performance
9. Visualize actual vs predicted values

## Dataset

The dataset contains Olympic team-level information such as:

- Team
- Country
- Year
- Number of athletes
- Average age
- Medals won in previous Olympic Games
- Medals won in the current Olympic Games

medals
